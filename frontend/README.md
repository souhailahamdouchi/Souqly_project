# SOUQLY - Frontend (Prototype React)

Ce projet est l'interface graphique (Frontend) de la marketplace SOUQLY, développé pour Maghreb Commerce Group.

## 🚀 Technologies utilisées
- **React 18** + **TypeScript** (via Vite)
- **Tailwind CSS** (Design System : Bleu SOUQLY, Orange SOUQLY)
- **Lucide React** (Icônes)
- **React Hot Toast** (Notifications)
- **React Context** (Gestion du bilingue FR/AR/EN avec support RTL)

## 📦 Installation et lancement
1. Cloner le projet.
2. Installer les dépendances : `npm install`
3. Lancer le serveur de développement : `npm run dev`
4. Ouvrir `http://localhost:5173` dans le navigateur.

## ✅ Fonctionnalités implémentées (Conforme au Cahier des Charges)
- **Site Public** : Accueil, Catégories, Catalogue avec filtres, Fiche produit détaillée.
- **Tunnel d'achat** : Panier multi-vendeurs, Checkout (Adresse + Paiement).
- **Espace Client** : Historique des commandes, Gestion des adresses, Profil.
- **Espace Vendeur** : Dashboard avec statistiques, Formulaire d'ajout de produit (Dropzone), Gestion des commandes.
- **Authentification** : Connexion / Inscription.
- **Pages Légales** : CGV / Mentions légales (Loi 09-08).
- **Internationalisation** : Support complet Français / Arabe (RTL) / Anglais.
